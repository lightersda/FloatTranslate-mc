# FloatTranslate · 悬浮窗屏幕翻译

一个 Windows 桌面悬浮翻译工具。把半透明的捕获窗口对准屏幕上**任何**文字
（游戏、图片、PDF、外文软件界面），即可识别并翻译成中文 —— 哪怕这些文字
本身无法复制。

## 特性

- **两种识别方式**，设置里一键切换：
  - **Windows 内置 OCR**（`Windows.Media.Ocr`）：本地运行、免费、快，适合大部分场景。
  - **直接发给模型**：把截图（灰度 JPEG）直发大模型，由模型"看图识别 + 翻译"一步出译文。
    对 OCR 误识（如把字母 `a` 认成 `0`）免疫，识别更准，适合要求高的场景。
- **多服务商**：Anthropic (Claude)、OpenAI、**本地模型**（LM Studio 等 OpenAI 兼容服务）、
  DeepSeek、Google (Gemini)，设置里切换；每个服务商 Key 单独保存。
- **本地模型免 Key**：连接本机 OpenAI 兼容服务（默认 `127.0.0.1:1234/v1`，可改），
  无需 API Key，支持视觉模型（如 Qwen3-VL）。
- **两种自动模式**：
  - **常规**：按设定间隔（默认 1.5s）自动重扫翻译。
  - **帧变化检测**：400ms 轻量轮询比对画面（80×45 灰度代理帧），**画面稳定约 0.8s 才翻译**；
    持续变化超 3s 强制翻译兜底（动画/视频不卡死）。滚动翻页不烧模型、遮罩不闪动。
- **方向**：任意语言 → 简体中文（可在设置里改目标语言）。

## 工作原理

```
透明捕获区 → mss 截取该区域屏幕 → Windows OCR 识别 / 直发模型一步出译文 → 显示译文
```

中间的捕获区用 Windows 的 `transparentcolor` 做成真正透明且**鼠标穿透**的
"洞"，截图拿到的是底层应用的画面，也能照常操作下面的程序。
图片直发时发送前会做预处理：**灰度 → 最长边 1280px → JPEG quality 75 → base64**，
显著降低本地视觉模型的推理耗时。

## 安装

需要 **Windows 10/11** 和 **Python 3.x**。

```powershell
pip install -r requirements.txt
```

> Windows OCR 依赖系统已安装的语言包。要识别某种语言，请在
> `设置 → 时间和语言 → 语言和区域` 里添加对应语言（当前已检测到：
> 英语 en-US、简体中文 zh-Hans-CN）。

## 配置

启动后点 ⚙ 打开设置：

1. **服务商**：
   - 云端服务（Anthropic / OpenAI / DeepSeek / Google）：填入对应 **API Key**，
     点「**验证并获取模型**」校验并拉取模型列表。
   - **本地模型**：Key 留空即可；可修改「本地模型 URL」（如 LM Studio 默认
     `http://127.0.0.1:1234/v1`、Ollama 的 `http://localhost:11434/v1`），
     再点「验证并获取模型」拉取本机模型。
2. **识别方式**：`Windows 内置 OCR` 或 `直接发给模型（一步出译文）`（仅 OpenAI /
   本地模型等支持视觉的服务可用）。
3. **自动模式**：`常规（按间隔翻译）` 或 `帧变化检测（稳定后翻译）`。
4. 选好模型、设好目标语言后点保存（写入 `%APPDATA%\FloatTranslate\config.json`）。

每个服务商的 Key 单独保存，可随时切换。留空时会回退到对应环境变量：
`ANTHROPIC_API_KEY` / `OPENAI_API_KEY` / `DEEPSEEK_API_KEY` /
`GOOGLE_API_KEY`（或 `GEMINI_API_KEY`）；本地模型无需任何 Key。

## 运行

```powershell
python app.py
```

或双击 `run.bat`（无控制台窗口）。

## 使用

| 操作 | 说明 |
|------|------|
| 拖动顶部标题栏 | 移动整个窗口 |
| 拖动右下角 ◢ | 调整大小 |
| **翻译** | 立即识别并翻译一次捕获区内容 |
| **自动:开/关** | 按所选自动模式定时检测并翻译 |
| **⚙** | 设置：服务商、Key、模型、目标语言、识别方式、自动模式等 |
| **×** | 关闭（自动记住窗口位置和大小） |

## 文件结构

| 文件 | 作用 |
|------|------|
| `app.py` | 悬浮窗主程序、界面与自动模式状态机 |
| `ocr.py` | Windows OCR 封装 |
| `providers.py` | 各服务商：校验 Key、列模型、文字翻译、图片直发（视觉） |
| `translator.py` | 翻译入口（内存缓存，文字/图片两条路径） |
| `config.py` | 配置读写 |

## 小贴士

- 捕获区**只框住要翻译的文字**，去掉无关画面，识别更准。
- 字太小识别差时，把目标程序字号调大或把捕获窗口拉大些。
- 「直接发给模型」准确率最高，但每次调用消耗模型算力（本地模型也吃显存/CPU）：
  配合**帧变化检测**自动模式，只在画面稳定后调用，最省。
- 本地模型推理慢时：确认已用 GPU 加载，或把 `translator.py` 中 `translate_image`
  的 `thumbnail((1280, 1280))` 改为 `(1024, 1024)` 进一步提速。
